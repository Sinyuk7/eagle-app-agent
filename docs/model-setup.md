# 模型配置

Remote API 和本地 Ollama 是两种平等的模型来源。选择时考虑数据流、费用、安装成本、本机资源、网络和服务商并发限制。

## Remote API

需要配置服务 endpoint、model，以及服务商要求的 API key。图片会上传到远程服务，可能产生调用费用。

交互设置会从模型目录选择 Remote 模型，并根据模型自动选择协议。已保存的服务地址可直接回车沿用，API key 留空会复用已保存凭证。

## 本地 Ollama

需要先安装 Ollama 和兼容视觉模型。Moodtag 会在开始标注时检查服务是否可连接，以及已安装模型是否明确支持 vision。
